Quy trình sản xuất 5 Style quảng cáo thú cưng

Từ 1 ảnh pet + ảnh các variant sản phẩm → tạo đủ bộ 5 hình quảng cáo (STL_01 → STL_05) cho mỗi variant. STL_01 là "ảnh gốc" – các style kỹ thuật phía sau đều được dựng trên nền STL_01.

Tổng quan Quy trình ⚡ MAKE PROMPT 🧩 Prompt theo Variant STL_01 STL_02 STL_03 STL_04 STL_05 Ví dụ thực tế Ma trận Variant Lợi ích

Tổng quan hệ thống 5 Style

Mỗi style phục vụ một nhu cầu khác nhau trên hành trình mua hàng: gây ấn tượng → kể câu chuyện → chứng minh chất lượng → chốt quyết định.

STL_01

Product Hero Shot

Ảnh studio phông trắng, ánh sáng high-key. Sản phẩm + pet phóng lớn sát lề, nhìn trực diện camera.

Mục tiêu: Gây ấn tượng

STL_02

Lifestyle Marketing

Ảnh lifestyle ấm áp + Typography: 1 Title ấn tượng và 1 Description ngắn nêu lợi ích.

Mục tiêu: Kể câu chuyện

STL_03

Functional Infographic

Giữ nguyên STL_01, phủ thêm mũi tên phát sáng / sóng khí để "thị giác hóa" tính năng vô hình.

Mục tiêu: Chứng minh công năng

STL_04

Exploded View

Bóc tách từng lớp chất liệu so le, có đường chỉ dẫn và nhãn tên từng lớp.

Mục tiêu: Chứng minh chất liệu

STL_05

Size Guide

Lưới 2x2 S/M/L/XL, pet thật đúng tỷ lệ, nhãn kích thước Dài x Rộng.

Mục tiêu: Chốt chọn size

Sơ đồ quy trình (Workflow)

Luồng phụ thuộc giữa các bước. Lưu ý: STL_03, STL_04, STL_05 dùng ảnh STL_01 đã tạo làm Base Image (media_id), nên phải hoàn thành và duyệt STL_01 trước.

📥 Input A – PetReference Image (nhân vật)
📥 Input B – VariantBase Image (ảnh sản phẩm từng màu)
📝 Input C – Dữ liệuOverview, Product Info, Material, Size
→
STL_01 Hero Shot (ảnh gốc) Pet (A) + Variant (B) · chọn Diễn xuất & Góc chụp · duyệt kỹ vì là nền cho các bước sau
→
STL_02A + B + Overview/Product Info → Lifestyle + Title/Description
STL_03Base = STL_01 + Mô tả sản phẩm → overlay công năng
STL_04Base = STL_01 + Material data → bóc tách lớp
STL_05Base = STL_01 + Size data → lưới S/M/L/XL

Các bước thực hiện chi tiết

Chuẩn bị input

Ảnh pet rõ mặt, đủ sáng (Reference Image). Ảnh từng variant sản phẩm trên nền trắng (Base Image). Soạn sẵn dữ liệu: Overview, Product Information, Thành phần cấu tạo, Bảng kích thước S/M/L/XL.

Upload & lấy media_id

Upload ảnh pet và từng ảnh variant lên công cụ tạo ảnh, ghi lại media_id cho từng ảnh (vd: PET_01, VAR_BLUE, VAR_GREY).

Tạo STL_01 cho từng variant

Điền template STL_01, chọn 1 Diễn xuất + 1 Góc chụp. Giữ cùng lựa chọn cho mọi variant để bộ ảnh đồng nhất. Duyệt: pet giống bản gốc, màu sản phẩm đúng variant, phông trắng sạch, bóng đổ tự nhiên. Lưu media_id của STL_01.

Tạo STL_02 (Lifestyle + chữ)

Dùng Pet + Variant, chèn dữ liệu Overview & Product Info để AI tự viết Title/Description và render chữ. Kiểm tra chính tả, chữ không bị méo, không che mặt pet.

Tạo STL_03, STL_04, STL_05 từ STL_01

Base Image = media_id của STL_01. Điền Mô tả sản phẩm / Material data / Size data tương ứng. Kiểm tra pet & sản phẩm không bị thay đổi so với STL_01.

QC & đặt tên file

Quy ước: {SKU}_{VARIANT}_{STL}.jpg – vd: COOLMAT_BLUE_STL01.jpg. Mỗi variant đủ 5 file. Lặp lại bước 3–6 cho variant tiếp theo.

Phân phối đa kênh

STL_01 → ảnh đại diện sàn TMĐT · STL_02 → Facebook/Instagram · STL_03/04/05 → phần mô tả chi tiết sản phẩm.

Tool

⚡ MAKE PROMPT – tạo đủ 5 prompt trong 1 lần

Chọn / nhập tham số cho cả 5 style rồi bấm Tạo prompt. Hình ảnh không cần nhập: prompt giữ chỗ [Reference Image], [Base Image], [STL_01 Image] để bạn gắn ảnh khi chạy. Dữ liệu bạn nhập được lưu tạm trên trình duyệt này.

Quy tắc đã cài sẵn trong mọi prompt:
  • Chữ trên ảnh ngắn gọn, dứt khoát: Title ≤ 4 từ, Description ≤ 8 từ, mỗi nhãn 1–3 từ. Càng ít chữ AI càng ít render lỗi.
  • Mọi ảnh đều tỉ lệ vuông 1:1 (vd 2048×2048).
  • STL_01: nền trắng tinh #FFFFFF, không gradient. Bóng đổ (nếu có) chỉ ở vùng sát sản phẩm và nhân vật.

STL_01

Hình ảnh Đại diện Sản phẩm (Product Hero Shot)

Đặc điểm
Ảnh studio sạch, nền trắng tinh #FFFFFF (không gradient), ánh sáng High-key, bóng đổ chỉ ở sát sản phẩm/pet. Chủ thể (sản phẩm + thú cưng) phóng lớn sát lề, nhìn trực diện camera.
Input
Reference Image (pet) + Base Image (variant sản phẩm)
Output
Ảnh gốc – được dùng làm Base cho STL_03, 04, 05
Kênh
Ảnh đại diện (thumbnail) trên sàn TMĐT

STL_02
Hình ảnh Giới thiệu Sơ lược (Lifestyle Marketing)

    

      
Đặc điểm
Kết hợp hình ảnh sản phẩm với chữ (Typography): 1 Title ấn tượng + 1 Description ngắn gọn, nổi bật lợi ích trên nền lifestyle ấm áp.

      
Input
Reference Image (pet) + Base Image (variant) + Overview + Product Information

      
Kênh
Facebook / Instagram / quảng cáo social

    


SCENE: Place the pet from [Reference Image] into the center of the product in the [Base Image]. The pet is [Action], looking pampered in a high-end lifestyle setting.

DATA INPUT FOR COPYWRITING:
Overview: [Dữ liệu Overview bạn cung cấp]
Product Information: [Dữ liệu Product Info bạn cung cấp]

CREATIVE TASK: Based on the DATA INPUT, write ONE punchy Title (max 4 words) and ONE Description line (max 8 words) about the single strongest benefit.

TEXT RULES: Only these two text elements appear in the image. Short, bold, decisive words. No paragraphs, no bullet lists, no extra labels, no logos. Spell every word correctly.

VISUAL TYPOGRAPHY: Place the Title and Description in the image's negative space, away from the pet's face. Clean, bold sans-serif font, large and highly legible, professionally aligned.

STYLE: Professional photography, soft natural lighting, realistic contact shadows, 8k resolution.

FORMAT: square 1:1 aspect ratio (e.g. 2048x2048 px); keep every element fully inside the square frame.

    
Lưu ý: Action nên dùng cùng giá trị với STL_01 để đồng bộ. Prompt đã giới hạn Title ≤ 4 từ, Description ≤ 8 từ. Vẫn cần kiểm tra chữ AI render (sai chính tả, lặp chữ) – nếu lỗi, có thể tạo ảnh không chữ rồi thêm chữ bằng công cụ thiết kế.

  







  

    
STL_03
Hình ảnh Mô tả Công năng (Functional Infographic)

    

      
Đặc điểm
Giữ nguyên ảnh STL_01, chèn thêm lớp đồ họa kỹ thuật (mũi tên phát sáng, sóng khí) để thị giác hóa tính năng vô hình: giải nhiệt, sưởi ấm, thoát khí.

      
Input
Base = media_id STL_01 + Mô tả sản phẩm

      
Kênh
Mô tả chi tiết sản phẩm (PDP)

    


BASE IMAGE: [Sử dụng media_id của hình ảnh STL_01 đã tạo].

FUNCTIONAL OVERLAY: Based on the Product Description: [Mô tả sản phẩm], add professional infographic elements to this image.

Overlay clean, high-end visual symbols (such as glowing arrows or airflow waves) that clearly demonstrate the product's benefits (e.g., cooling, heat dissipation, breathability).
The graphics must be harmoniously integrated onto the product surface without altering or editing the existing pet or the product itself.

TEXT RULES: At most 3 very short labels (1-3 words each), or no text at all. No sentences.

GOAL: Create a simple, easy-to-understand functional diagram that showcases the technology within the original professional studio setting. Keep it clean and premium.

FORMAT: square 1:1 aspect ratio (e.g. 2048x2048 px); keep every element fully inside the square frame.

  







  

    
STL_04
Sơ đồ Bóc tách Cấu tạo (Exploded View Diagram)

    

      
Đặc điểm
Hình ảnh kỹ thuật bóc tách từng lớp chất liệu so le, đường kẻ chỉ dẫn + nhãn tên để chứng minh chất lượng vật liệu & công nghệ bên trong.

      
Input
Base = STL_01 + Thông tin thành phần cấu tạo (Material data)

      
Kênh
Mô tả chi tiết sản phẩm (PDP)

    


SCENE: Create a high-end professional exploded-view diagram based on the product in [Base Image STL_01].

MATERIAL DATA: [Thông tin thành phần cấu tạo bạn cung cấp].

TASK: Analyze the MATERIAL DATA to visualize the product's internal construction. Display the different layers (surface, middle, and back) peeled apart and stacked in a clean, diagonal 3D arrangement to showcase their unique textures.

DIAGRAM ELEMENTS:
- Add clean, thin leader lines pointing precisely to each revealed layer.
- One short label per layer (1-3 words, e.g. "Ice Silk"), taken from the material names. No descriptions or sentences.
- Use high-end sans-serif fonts for a premium catalog look.

STYLE: Pure white studio background, realistic fabric textures, soft technical lighting, 8k resolution, professional commercial quality.

FORMAT: square 1:1 aspect ratio (e.g. 2048x2048 px); keep every element fully inside the square frame.

  







  

    
STL_05
Bảng Hướng dẫn Chọn Size (Size Guide Infographic)

    

      
Đặc điểm
Bố cục lưới (Grid) trình bày S, M, L, XL. Kết hợp hình ảnh thú cưng thật theo đúng tỷ lệ so sánh để khách dễ quyết định.

      
Input
Base = STL_01 + Kích thước S/M/L/XL

      
Kênh
Mô tả chi tiết sản phẩm, ảnh cuối trong gallery

    


SCENE: Create a professional size guide infographic for the pet cooling mat based on the product in [Base Image STL_01].

INFOGRAPHIC LAYOUT: Arrange the image into a clean 2x2 grid representing four sizes: S, M, L, and XL.

SIZE DATA: Use the following information for each grid cell:
Size S: [Kích thước S] - "Cats"
Size M: [Kích thước M] - "Small Dogs"
Size L: [Kích thước L] - "Medium Dogs"
Size XL: [Kích thước XL] - "Large Dogs"

VISUALS: In each cell, show the product with a realistically scaled pet (cat or dog) to demonstrate the fit. Each cell has only three text elements: the size badge (S/M/L/XL), the dimension (Length x Width) and the short fit label in quotes. No other text.

STYLE: Pure white studio background, clean commercial typography, consistent high-end lighting across all cells. 8k resolution, professional advertising quality.

FORMAT: square 1:1 aspect ratio (e.g. 2048x2048 px); keep every element fully inside the square frame.
